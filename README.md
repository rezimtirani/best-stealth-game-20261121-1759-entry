**The Lantern Thief** — a complete top-down stealth game, played in a desktop browser from static files, no network needed. You are Wren, a hooded thief stealing the moon-lanterns of House Varra across three walled gardens at night. Guards patrol with vision cones; lamplight sees you faster, shadow and rose bushes hide you. Walk loudly and guards come to investigate; get fully spotted and they chase. Steal every lantern, then slip out through the green door — unseen.

- 3 levels (Courtyard, Rose Maze, Vault Garden), 2–4 patrolling guards each
- Vision cones that turn orange when suspicious and red on alarm, with a detection meter over each guard
- Sneak (Shift) to move silently; walking makes noise guards can hear
- Bushes hide you, lamps light you up, patrols you can learn
- Synthesised WebAudio sound (footsteps, pickup chimes, alarm) — no audio files
- Score, attempts, timer, pause, restart, title / level-clear / win screens

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Move with WASD or arrow keys, hold Shift to sneak, R restarts the level, P pauses, M mutes, Enter confirms.
